# 闲鱼接单工作室

> 个人程序员在闲鱼接单 + 售卖小工具的工作空间。
> 这个项目的核心用途：**让 AI 来生成文案**，归档后随时取用，而不是让你自己手写。

技术栈：Java · Python · Vue · 嵌入式 · 网页/后台开发

---

## 怎么用这个项目

**你只要在对话里告诉我产品/需求，我直接给你写好文案并存进项目归档**，你复制去闲鱼用即可。

比如你说：
- "帮我写个图片批量加水印工具的上架文案"
- "客户问 ESP32 课设能不能做，报多少，帮我写回复"
- "刚接了个 PDF 合并的单，写个交付使用说明"

我就会按本项目的风格规范生成文案，存到 `copywriting/generated/`，并给你看。

## 文案风格规范

所有文案统一调性，写在 [copywriting/STYLE.md](copywriting/STYLE.md)，我每次生成都遵守：
- **专业实在**，不浮夸、不吹、营销味克制
- 说清楚能做什么、不能做什么、买家要准备什么
- 拒绝套话堆砌和 emoji 刷屏

## 目录结构

```
xianyu/
├── README.md                   # 本文件
│
├── copywriting/                # 文案库（AI 生成 + 归档）
│   ├── STYLE.md                # ★ 文案风格规范（我生成时遵守的准则）
│   ├── generated/              # 已生成的成品文案（按日期/品类归档）
│   └── templates/              # 结构参考模板（我生成时的骨架，不必你手动填）
│
├── ops/                        # 运营记录
│   ├── 冷启动方案.md            # ★ 新号 0-30 天怎么做（含风险红线）
│   ├── 数据获取方案.md          # 商品数据自动获取的可行路径调研
│   ├── 数据采集使用说明.md       # ★ 采集浏览量/想要数的完整步骤
│   ├── _商品登记模板.md          # 已上架商品填空模板（贴文字给 AI 登记）
│   ├── tools/
│   │   └── xianyu_stats.py     # JSON → 复盘表 + 增量对比脚本
│   ├── data/                   # 采集的原始 JSON 与快照
│   ├── ideas.md                # 待开发小工具选题清单
│   ├── listings.md             # 已上架商品清单
│   └── orders.md               # 订单记录
│
├── products/                   # 可售卖小工具开发项目（如 photo-sorter）
└── templates/                  # 脚手架与模板
    ├── _新项目启动模板.md          # ★ 做新产品填空发我，产出方案+Cursor提示词
    └── _新项目启动模板-样例.md      # photo-sorter 实际填法参考
```

> `products/` 存具体产品的方案、代码、Cursor 提示词、开发日志。
> `templates/_新项目启动模板.md` 是做新产品时填空发我的模板,照样例填即可。

## 四类文案

| 类型 | 何时找我 | 存到哪 |
|---|---|---|
| 商品上架文案 | 开发完一个工具要上架闲鱼时 | `copywriting/generated/商品/` |
| 引流推广文案 | 想发朋友圈/小红书引流时 | `copywriting/generated/引流/` |
| 客户沟通话术 | 接单时跟客户聊、报价、催尾款 | `copywriting/generated/话术/` |
| 产品说明/教程 | 交付工具时要附使用说明 | `copywriting/generated/说明/` |

## 运营记录

- 有新工具点子 → 告诉我，我加进 `ops/ideas.md`
- 上架后 → 告诉我链接和价格，我登记到 `ops/listings.md`
- 接单成交 → 告诉我客户和需求，我登记到 `ops/orders.md`

这些也都可以让我来记，你不用手动改文件。

## 跟 DSH 配合

本项目用 DSH（DeepSeek Harness）+ 本地国产大模型代理辅助生成文案。
配置已写入 DSH 运行配置（`/home/www/.dsh/`），本项目内不保留配置脚本。
可用模型：glm-5.2、deepseek-v4-pro/flash、kimi-k2.6、minimax-m3、混元 2.0 等。
