## 数据采集命令

```bash
cd tools/xianyu-search
export HOME=/home/www/xianyu

# 在售商品清单
python3 scripts/xianyu.py myitems

# 浏览/想要数（需 x5sec token）
python3 scripts/xianyu.py itemstats --out ../../ops/data/stats-$(date +%F).json

# 转复盘表
cd ../..
python3 ops/tools/xianyu_stats.py snapshot ops/data/stats-*.json
python3 ops/tools/xianyu_stats.py report
python3 ops/tools/xianyu_stats.py diff
```
