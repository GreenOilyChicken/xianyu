# 闲鱼数据采集使用说明

> 配套脚本：[xianyu_stats.py](tools/xianyu_stats.py)
> 背景调研：[数据获取方案.md](../数据获取方案.md)

---

## 这套东西干什么

用 [xianyu-skills](https://github.com/donggeai/xianyu-skills) 读你自己闲鱼商品的
**浏览量 / 想要数**，再用本项目脚本转成复盘表，能看出**每天的增量**。

```
xianyu-skills（浏览器扩展+CLI）      xianyu_stats.py（本项目）
   读页面 → JSON  ──────────────→  存快照 → 复盘表 + 增量 + 结论
```

---

## 一、安装（只做一次）

### 1. 环境要求

- Python ≥ 3.11
- Google Chrome
- 一个已登录的闲鱼账号

### 2. 获取代码

> ⚠️ **`git clone` 在本机被阻断**（GnuTLS TLS 错误），用 tarball 下载：

```bash
mkdir -p ~/tools && cd ~/tools
curl -sL -o xs.tar.gz \
  https://codeload.github.com/donggeai/xianyu-skills/tar.gz/refs/heads/main
tar xzf xs.tar.gz && mv xianyu-skills-main xianyu-skills
```

### 3. 装依赖

```bash
cd ~/tools/xianyu-skills
pip install requests websockets
# 或用 uv：uv sync
```

### 4. 加载 Chrome 扩展

1. Chrome 打开 `chrome://extensions/`
2. 右上角开「**开发者模式**」
3. 点「**加载已解压的扩展程序**」
4. 选择 `~/tools/xianyu-skills/extension/` 目录
5. 确认出现 **Xianyu Bridge**

## 二、采集数据

### 启动桥接服务

CLI 会自动拉起 `bridge_server.py`（监听 `ws://localhost:9444`），
也可以手动启动：

```bash
cd ~/tools/xianyu-skills
python scripts/bridge_server.py
```

> Chrome 必须开着，扩展图标点开显示「**已连接**」才能工作。

### 采集命令

```bash
cd ~/tools/xianyu-skills

# 1) 检查登录
python scripts/cli.py check-login

# 2) 列出我的商品（拿到 item_id）
python scripts/cli.py list-my-items

# 3) 读单个商品的浏览/想要
python scripts/cli.py get-item-stats --item-id 812345678901
```

`get-item-stats` 的实际返回（**已核对源码** `scripts/xianyu/product_ops.py`）：

```json
{
  "item_id": "812345678901",
  "title": "小学二年级口算题50份｜2000道不重复｜A4可打印含答案",
  "price": "9.9",
  "wanted": "23",
  "views": "1.2万",
  "url": "https://www.goofish.com/item?id=812345678901"
}
```

### 存到本项目

```bash
cd ~/tools/xianyu-skills
OUT=~/xianyu/ops/data          # 换成你的实际路径
mkdir -p $OUT

python scripts/cli.py list-my-items > $OUT/my-items-$(date +%F).json

# 逐个商品抓浏览/想要（item_id 从上面列表里取）
for id in 812345678901 812345678902; do
  python scripts/cli.py get-item-stats --item-id $id > $OUT/stats-$id.json
done
```

## 三、生成复盘表

```bash
cd ~/xianyu

# 把本次 JSON 存成快照
python ops/tools/xianyu_stats.py snapshot ops/data/*.json

# 看复盘表（第二次起自动带增量）
python ops/tools/xianyu_stats.py report

# 只看最近两次的增量
python ops/tools/xianyu_stats.py diff
```

输出示例：

```
| 商品 | 价格 | 浏览 | 浏览增量 | 想要 | 想要增量 |
|---|---|---|---|---|---|
| 小学二年级口算题50份｜2000道不重复｜A4可打印含答案 | ¥9.9 | 15000 | +3000 | 31 | +8 |
| 小学口算题全套｜1-4年级7个版本｜322份可打印含答案 | ¥29.9 | 3400 | 0 | 8 | 0 |

## 结论
- **「想要」最高**：小学二年级口算题…（31）→ 它的标题关键词值得铺到其他商品
- **曝光增长最快**：小学二年级口算题…（+3000）→ 观察它靠什么关键词进来的
```

结论部分会自动套用 [冷启动方案](../冷启动方案.md) 第八节的判据：
零曝光 → 换标题重发；有浏览无想要 → 改首图。

## 四、脚本能解析的输入

`xianyu_stats.py` 兼容三种 JSON：

| 来源 | 含浏览/想要 | 说明 |
|---|---|---|
| `get-item-stats` | ✅ | **主要数据源** |
| `get-item-detail` | ✅ | 字段相同，也能用 |
| `list-my-items` | ❌ | 只有 url/title，用来补全商品清单 |

多个文件一起传即可，同 item_id 的记录会自动合并
（有值的字段不会被空值覆盖）。

## 五、已知限制（重要）

### 1. 浏览量过万后有精度损失

闲鱼页面在超过 1 万后**只显示 1 位小数**（`1.2万`）。
所以 `12000` 和 `12900` 都显示成 `1.2万`，
**此时 `+0` 的增量可能是精度问题，不代表真的没涨**。

判断方法：如果浏览量已经过万，别只看增量，也看「想要」数的变化。

### 2. 依赖页面结构，平台改版就会失效

数据靠**正则匹配页面文本**（`X人想要`、`X浏览`）拿到，见源码
`scripts/xianyu/item_detail.py`。闲鱼改版 → 匹配失败 → 字段变 `null`。

**如果 `views`/`wanted` 一直是 `null`，先手工打开商品页确认页面上还有没有这两个数字。**

### 3. 拿不到订单和成交数据

`get-item-stats` 只有浏览/想要。成交、收入要自己从闲鱼 App 看，
或登记进 [orders.md](../orders.md)。

### 4. 只读相对安全，写操作风险高

本项目**只用只读命令**（`check-login` / `list-my-items` / `get-item-stats`）。

xianyu-skills 还有 `publish` / `send-message` / `want-item` 等**写操作**，
会自动操作你的真实账号 —— **不建议用**，风控风险见
[数据获取方案](数据获取方案.md) 第三节。

### 5. 未实测的部分

- [ ] Chrome 扩展在你的 Chrome 版本能否正常加载
- [ ] `get-item-stats` 在**真实页面**是否真能抓到 views/wanted
- [ ] 闲鱼网页版是否仍展示这两个数字

> 这三项需要你在本地跑一次验证。**如果 views/wanted 抓不到，
> 脚本的其他部分仍然可用，只是数据源要换。**

## 六、采集节奏建议

| 频率 | 动作 |
|---|---|
| 每 3 天 | 跑一次采集 + `snapshot`，看增量 |
| 每周 | 看 `report` 的结论，按判据调整标题/首图 |
| 每月 | 数据汇总进 [listings.md](../listings.md) 的复盘表 |

> 别太频繁（一天多次）。反复访问自己的商品页也可能触发风控。

---

## 七、安全提醒

审查源码时注意到扩展的两个能力，**你自己用要知道**：

1. **`cmdEvaluate` 用 `eval()` 在页面主世界执行任意 JS**
   （`extension/background.js:120-132`）——
   意味着 CLI 能对 goofish.com 页面执行任意脚本。
2. **`get_cookies` 能导出 goofish.com 的全部 cookie**
   （`background.js:281-283`）——
   这个 cookie 等同于你的登录态。

**所以**：只在你信任的机器上跑，不要把 bridge 端口（9444）暴露到公网，
不要装来路不明的 fork。本项目脚本本身**不碰 cookie**，只用页面文本。
