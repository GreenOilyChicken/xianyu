# 商品登记模板

> 用法：复制下面的表头，每个已上架商品填一行，填完发我（或直接说"读一下这个文件"）。
> 我会读取并登记进 [listings.md](listings.md)。
>
> **为什么用文字不用截图**：当前模型 `deepseek-v4-flash` 不支持图片输入（已实测）。
> 想发截图需先切换到 Kimi-K2.6 / MiniMax-M3 等声明支持 image 的模型。

| 日期 | 商品标题 | 形态 | 价格 | 闲鱼链接 | 月销量 | 状态 |

|  |  |  |  |  |  |  |

**字段说明**

- **日期**：上架日期，如 `2026-10-08`
- **商品标题**：闲鱼上的完整标题（我用来对照关键词布局是否合理）
- **形态**：`PDF内容包` / `Python exe` / `定制服务` / `桌面程序`
- **价格**：写实际挂出价，如 `¥9.9`
- **闲鱼链接**：App 里商品分享出来的链接，没有可留空
- **月销量**：刚上架填 `-`
- **状态**：`上架中` / `已售罄` / `已下架`

## 可选：顺便告诉我这些（有就填，没有跳过）

> 这些信息能让我给出更准的优化建议，不填也不影响登记。

### 1. 曝光情况
- 有曝光但没人问的商品是哪些？
- 完全零曝光的商品是哪些？

### 2. 咨询情况
- 有人问但没成交吗？买家主要问什么？

### 3. 竞品观察（冷启动期 Day1-3 该做的）
- 你看到的同类商品卖多少钱？
- 有没有同行的标题/首图你觉得做得好？

## 登记后我会做什么

1. 把上面表格的内容写进 `listings.md`，并从「待上架」表移除对应行
2. 对照 [STYLE.md](../copywriting/STYLE.md) 检查你的标题关键词布局，有问题给修改建议
3. 如果多个商品标题关键词重叠（自己抢自己流量），提醒你改
4. 按 [冷启动方案](冷启动方案.md) 第五节的虚拟品红线，检查有没有违规风险点
