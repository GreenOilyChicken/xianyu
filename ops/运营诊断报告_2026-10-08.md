## 二、竞品行情（代做服务赛道）

### "软件开发代做"（60 个样本）

- **价格中位 ¥10**，主流带 ¥10-20（25 个）
- **想要数断层式头部**：PLC 代做 15787、Python 代做 10196——这些是铺了多年的老链接
- ¥10 这个价位是**走量主力带**

### "Java Web 代做"（60 个样本）

- **价格中位 ¥9**，比通用"软件开发"更低
- 头部 ¥39.99 那条想要 2550——说明**Java Web 赛道愿意付到 ¥40 的人不少**
- ¥8.8/¥9.9 是引流价，¥39.99 是利润款

### 关键结论

1. **引流价模式成立**：标价低拿"我想要"进咨询，成交靠改价（¥20 起）。
   竞品 ¥10 标价想要上万、¥39.99 标价想要 2550，印证标价是咨询入口。
2. **爆款标价 ¥9 是对的**——卡在主流带，93 个咨询入口，别动。
3. **C# Electron ¥50 的问题不在 C# 本身，在标价**：¥50 在代做服务里是高标价，
   把想咨询的人挡在"我想要"之前就退了。降到 ¥9.9 拿咨询量，靠改价成交。
4. **自相残杀和实物拖累的问题不变**（见下）。

## 四、两三个没上架的项目怎么上

你提到还有两三个项目没上架。根据竞品数据，给你上架策略：

### 上架原则（从竞品数据反推，引流价模式）

1. **标价 = 引流价**：¥8.8-9.9 卡主流带拿咨询入口，成交靠改价（¥20 起）
2. **标题公式**：`技术栈 + 代做/定制 + 具体能做什么 + 交付方式`
3. **不要和现有爆款标题重叠**——每上个新品，先搜一下自己的标题，确保不和
   `软件开发项目代做Javaweb jsp` 抢词
4. 虚拟/工具类商品另算（参考口算内容包：程序生成、零版权、标价即成交价）

### 具体建议

**如果是 Java/Web 方向的新项目**：
- 标价 ¥9.9 引流（卡主流带，拿咨询入口）
- 标题含"Java Web 代做""SpringBoot""管理系统"等精准词
- 成交靠改价，¥20 起；复杂项目可报到更高

**如果是 Python/数据分析方向**：
- 竞品里 Python 代做想要 10196——**这是比 Java 更大的赛道**
- 标价 ¥9.9，标题 `Python代做｜爬虫/数据分析/机器学习｜985水平`
- 这条有机会成为第二个爆款（咨询入口大）

**如果是工具类（exe/桌面程序）**：
- 这类**不是代做服务，是成品售卖**——标价就是成交价，不走改价
- 参考你的口算内容包思路——**程序生成的虚拟资料，零版权、零售后**
- 标价 ¥5.9-9.9，标题关键词前置
- 这条线和代做服务**人群不重叠但搜索驱动**，可以共存（冷启动方案 6.4 节）
