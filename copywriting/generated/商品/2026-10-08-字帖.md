## 生产命令（如需重新生成或调整字表）

```bash
# 从内置字表生成三个版本
python src/main.py --mode zitie --char-file assets/chars_3500.txt \
    --style miaohong --out out/字帖内容包/常用字字帖_描红.pdf --title "常用字字帖·描红版"

python src/main.py --mode zitie --char-file assets/chars_3500.txt \
    --style linmo --out out/字帖内容包/常用字字帖_临摹.pdf --title "常用字字帖·临摹版"

python src/main.py --mode zitie --char-file assets/chars_3500.txt \
    --style hunhe --out out/字帖内容包/常用字字帖_混合.pdf --title "常用字字帖·混合版"

# 自定义字表
python src/main.py --mode zitie --chars "永和九年" --style miaohong --out 我的字帖.pdf
```

> 字表文件 `assets/chars_3500.txt` 可替换为自定义字表（一行一个字，或连续书写均可）。
> 替换后重新运行上面的命令即可生成对应的字帖。
