# 客户沟通话术 · 结构参考

> AI 生成接单沟通话术时的骨架，按场景分。措辞按 [STYLE.md](../STYLE.md)。

## 报价话术
```
您好，[需求] 这个我能做。
具体方案：[1-2句讲怎么做]
交付：[给什么/几天]
价格：¥[X]，定金 ¥[Y] 开工，尾款交付后付。
[可选：加急说明 / 需要确认的点]
```

## 催尾款话术
```
您好，[需求] 已按约定交付：
[交付物清单]
您验收下，有问题这两天随时说。
没问题的话麻烦结下尾款 ¥[X]，辛苦了。
```

## 拒绝话术（不接的单）
```
您好，这个需求我做不了 / 不在接单范围，[一句原因]。
[可选：建议他找谁/怎么做]
```

## 约束
- 短、直接、给具体数字
- 不绕弯子，不卑不亢
- 不用"亲""宝"等称呼
