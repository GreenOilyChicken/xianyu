# 闲鱼文案风格规范

> 本文件是 AI 生成闲鱼文案时必须遵守的准则。每次生成前对照本规范，确保产出"专业实在"的文案，而不是浮夸营销腔。
> 这个规范的存在，就是为了让文案"不像 AI 写的"。

---

## 一、总调性：专业实在

一个程序员在闲鱼接单，靠的是**技术可信**，不是话术。文案要让人读完觉得"这人懂行、能交付、不忽悠"。

### 要做到
- 把工具/服务**能干什么**讲具体，能用数字就用数字（"批量处理 100 张图""3 秒完成"）
- 主动说**适用边界**和**不包含什么**，反而显得靠谱
- 价格、交付方式、售后范围** upfront 写清**，减少来回问
- 像跟一个不太懂技术的客户当面解释，平实、有信息量

### 绝对不做
- ❌ 堆砌"全网最低""限时抢购""手慢无"等营销词
- ❌ emoji 刷屏（一两个点睛可以，三五连发就停）
- ❌ "亲爱的宝子们""家人们"这类称呼
- ❌ 没有信息量的形容词："超好用""超级方便""绝绝子"
- ❌ 虚假承诺："包学包会""永久免费更新"（除非真做到）
- ❌ 把功能吹成魔法："一键搞定一切""彻底解决"

## 二、四类文案的具体规范

### 1. 商品上架文案

结构（按这个顺序，缺的项可省）：

```
【标题】工具名｜一句话核心价值｜交付方式
  - 标题 ≤ 30 字，关键词前置（闲鱼搜索靠标题）
  - 例：图片批量加水印工具｜3秒处理100张｜exe即开即用

【正文】
痛点切入（1-2句，描述客户遇到的麻烦）
↓
这是什么（讲清楚功能，用动词+名词，别用形容词）
↓
适合谁用（列人群）
↓
主要功能（要点列表，每条一个具体功能）
↓
为什么选它（跟同行/手动做法比，说具体优势）
↓
交付内容（exe/源码/教程视频，列清楚）
↓
使用要求（系统/环境，写明白）
↓
常见问题（2-3条，真实FAQ）

【售后】交付后X天免费修bug，新功能另报价
【拍前必读】3条以内，最重要的边界
```

**要点**：正文不超过 400 字，闲鱼没人看长文。功能用"能做什么"表述，不用"不能做什么"开头。

### 2. 引流推广文案（朋友圈/小红书/快手）

结构：

```
钩子句（一个具体场景/数字，不夸张）
↓
痛点（你或客户遇到的真实麻烦）
↓
方案（自然引出工具/服务，不硬推）
↓
引导（怎么找到我：闲鱼搜XXX / 私信）
```

**要点**：
- 钩子用**具体数字或场景**，不用感叹号轰炸
- 像分享经验，不像打广告
- 小红书可适当加 3-5 个相关话题标签，朋友圈不加
- 长度：朋友圈 ≤ 100 字，小红书 150-250 字

### 3. 客户沟通话术

按场景分：

**报价话术**：
```
您好，[需求] 这个我能做。
具体方案：[1-2句讲怎么做]
交付：[给什么/几天]
价格：¥[X]，定金 ¥[Y] 开工，尾款交付后付。
[可选：加急说明 / 需要确认的点]
```

**催尾款话术**：
```
您好，[需求] 已经按约定交付完成了：
[交付物清单]
您验收下，有问题这两天随时说。
没问题的话麻烦结下尾款 ¥[X]，辛苦了。
```

**拒绝话术**（需求不接时）：
```
您好，这个需求我做不了 / 不在接单范围，[一句原因]。
[可选：建议他找谁/怎么做]
```

**要点**：话术要短、要直接、要给具体数字。不绕弯子，不卑不亢。

### 4. 产品说明 / 教程文案

结构：

```
这是什么（一句话）
↓
准备（运行环境/前置条件）
↓
怎么用（步骤化，1. 2. 3.，配截图位）
↓
常见问题（FAQ表格）
↓
出问题怎么办（联系方式 + 售后边界）
```

**要点**：
- 假设客户完全不懂技术，每步写到位
- 步骤用编号列表，不用大段文字
- 截图位置用 `[图：XXX]` 占位，提示配图

## 三、格式与细节

### 标点与排版
- 用中文标点（，。？！）
- 标题用【】，不用 emoji 当标题
- 列表用 `-` 或 `1.`，不混用
- 价格用 `¥9.9` 格式，不用"9块9"

### 数字
- 处理量、时长等**用具体数字**（"100张""3秒"），不用"很多""很快"
- 报价**写死具体金额**，不写"面议""详询"（除非真没法定）

### 禁用词清单（出现即重写）
| 禁用 | 改用 |
|---|---|
| 性价比之王 / 天花板 | （删掉，直接讲配置和价值） |
| 宝子们 / 家人们 | （直接称呼"您"或省略） |
| 绝绝子 / yyds | （删掉） |
| 一键搞定一切 | 写明具体一键搞定什么 |
| 永久免费更新 | 写明更新周期和范围，或删掉 |
| 限时秒杀 | （闲鱼用不上，删掉） |
| 纯手工打造 | （除非真是，否则删掉） |

### 闲鱼平台适配
- 标题前 15 字最关键（搜索权重），把工具名和核心功能放前面
- 详情首屏要看到价格和交付物
- 不要在文案里留微信/手机号（违规），引流走闲鱼私信

## 四、生成后的自检清单

每次生成文案，对照这个清单过一遍：

- [ ] 没有"AI 味"营销词（对照禁用词清单）
- [ ] emoji ≤ 2 个
- [ ] 有具体数字，没有"很多/很快/超"
- [ ] 说了能做什么，也说了边界/不包含什么
- [ ] 价格、交付方式、售后都写清
- [ ] 长度合适（商品 ≤400 字，朋友圈 ≤100 字）
- [ ] 闲鱼标题关键词前置
- [ ] 没有"亲爱的/宝子们/家人们"

任何一条不达标，重写后再交付。
